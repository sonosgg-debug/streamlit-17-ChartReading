# Technical Analysis Pro (기술적 분석 대시보드)

한국(KRX) 및 미국(US) 개별 종목의 주가 차트와 다양한 보조지표(이동평균선, 볼린저 밴드, MACD, RSI, 스토캐스틱, 거래량 등)를 정량적으로 분석하여 **전문가 관점의 5단계 투자 의견** 및 세부 분석 리포트를 제공하는 웹 애플리케이션입니다.

---

## 📌 주요 기능

1. **글로벌 증시 지원**:
   - **한국 증시 (KRX)**: 코스피, 코스닥 전 종목 (삼성전자, SK하이닉스 등 주요 종목 퀵 선택 및 6자리 코드/종목명 직접 입력 지원)
   - **미국 증시 (US)**: NYSE, NASDAQ 전 종목 (Apple, NVIDIA, Tesla 등 주요 종목 퀵 선택 및 티커 직접 입력 지원)

2. **다양한 분석 주기 및 기간**:
   - **분석 대상 (주기)**: 일봉 (Daily), 주봉 (Weekly), 월봉 (Monthly)
   - **조회 기간**: 1Y, 3Y, 5Y, 10Y, 20Y (최장 20년 장기 차트 및 거시 사이클 분석 가능)

3. **전문가 관점의 5단계 투자 의견 모델**:
   - **매수 (Buy)**: 강력한 상승 추세 및 모멘텀 지속 (종합 점수 +45 ~ +100점)
   - **비중확대 (Overweight)**: 안정적 우상향 및 눌림목 반등, 분할 매수 유리 (종합 점수 +15 ~ +44점)
   - **중립 (Neutral)**: 박스권 횡보 및 추세 탐색, 관망 및 방향성 확인 권장 (종합 점수 -14 ~ +14점)
   - **비중축소 (Underweight)**: 단기 고점 징후 또는 지지선 위협, 차익실현 고려 (종합 점수 -44 ~ -15점)
   - **매도 (Sell)**: 역배열 심화 및 하락 추세 지속, 리스크 관리 및 현금화 (종합 점수 -100 ~ -45점)

4. **고해상도 동기화 인터랙티브 차트 (Plotly)**:
   - **Row 1**: 캔들스틱 + 이동평균선(5/20/60/120/200) + 볼린저 밴드(20,2) + 1차 지지/저항선 가이드라인
   - **Row 2**: 거래량 바 차트 (양봉/음봉 색상 연동) + 20일 거래량 이동평균선
   - **Row 3**: MACD 선 + Signal 선 + MACD 히스토그램 (0선 기준)
   - **Row 4**: RSI (14) + 70(과매수)/30(과매도) 채움 밴드
   - 모든 보조지표의 X축 줌/팬(Pan)이 일체형으로 실시간 연동

5. **심층 기술적 분석 카드 및 실전 매매 전략**:
   - 4대 영역별 상세 진단: 이동평균선/추세, 모멘텀, MACD 추세 강도, 볼린저/거래량 수급
   - 핵심 지지선/저항선 가격대(1차·2차) 및 ATR 기반 권장 손절선(Stop-loss), 1차 목표가 자동 계산
   - 신규 매수자 접근 전략, 기존 보유자 대응 전략, 리스크 관리 수칙 제공

## 🚀 실행 방법

### 방법 1. 배치 파일 실행
프로젝트 폴더 내 `run_app.bat` 파일을 더블클릭합니다.

### 방법 2. 터미널 명령어 실행
```bash
streamlit run app.py
```
브라우저에서 `http://localhost:8501`로 접속하여 대시보드를 사용하실 수 있습니다.

---

## 📂 파일 구조
- `app.py`: Streamlit 메인 UI (사이드바, 대시보드 카드, 메트릭, 레이아웃)
- `data_loader.py`: FinanceDataReader 및 yfinance 기반 한/미 증시 데이터 로더 및 리샘플링
- `analyzer.py`: 기술적 보조지표 계산, 정량적 스코어링 및 5단계 투자 의견 도출 엔진
- `chart_plotter.py`: 4개 행 동기화 Plotly 인터랙티브 금융 차트 생성 모듈
- `requirements.txt`: 의존성 패키지 목록
- `run_app.bat`: 윈도우 원클릭 실행 배치 파일
- `test_suite.py`: 다양한 종목/기간/주기 통합 검증 테스트 스위트
